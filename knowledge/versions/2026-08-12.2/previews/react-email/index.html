使用建议

建议

  • 建议：基于 Refero 采集图和 metadata 还原 React Email 的颜色、字体和页面密度，优先服务 暗色界面、AI、专业工具 场景。
  • 建议：保留 React Email 的来源标签和视觉 token，不把它混入旧来源的泛化模板。

避免

  • 避免：不要把 React Email 套用到与 暗色界面、AI、专业工具 明显无关的产品语境。
  • 避免：不要用通用行业模板覆盖 React Email 的采集图风格；需要保留原图里的版式密度、留白和视觉重心。
