使用建议

建议

  • 建议：Use Primer dark default: canvas {#0D1117}, surfaces {#161B22} / {#21262D}, borders {#30363D}。
  • 建议：Reserve green {#238636} for the "Code" download and "Merge pull request" buttons ONLY。
  • 建议：Use accent blue {#2F81F7} for links, {owner/name}, and active/selected states。
  • 建议：Color state semantically: open = green {#3FB950}, merged = purple {#A371F7}, closed = red {#F85149}, draft = grey。
  • 建议：Render the contributions heatmap with the exact 5-step ramp {#161B22 → #0E4429 → #006D32 → #26A641 → #39D353}。

避免

  • 避免：use the green {#238636} for generic CTAs — it specifically means "download code / merge"。
  • 避免：swap state colors — merged is ALWAYS purple, closed is ALWAYS red; developers read these instantly。
  • 避免：render code, SHAs, or file paths in the sans face — monospace is the contract。
  • 避免：use drop-shadows to separate cards — use borders + surface steps。
  • 避免：wrap long code lines — code scrolls horizontally。
