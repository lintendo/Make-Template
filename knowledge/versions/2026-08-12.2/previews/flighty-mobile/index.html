使用建议

建议

  • 建议：Use {#0B0B0F} as the canvas — deep, premium instrument-panel black。
  • 建议：Reserve Flighty Blue ({#0A84FF}) for the primary action, the live arc, and active states。
  • 建议：Keep status colors strict: green = on time, amber = delayed, red = cancelled — chips only。
  • 建议：Render the live flight map arc as the screen's hero — the map exists to host it。
  • 建议：Use tabular figures for all flight data (times, gate, terminal, on-time %)。

避免

  • 避免：use pure black {#000000} as the canvas — {#0B0B0F} keeps depth in the map。
  • 避免：use status colors decoratively — green/amber/red mean exactly on-time/delayed/cancelled。
  • 避免：add accent colors beyond blue — the restraint makes the status colors read instantly。
  • 避免：let chrome compete with the map — the arc must be the strongest element。
  • 避免：use proportional figures for times — they jitter as data updates; use tabular。
