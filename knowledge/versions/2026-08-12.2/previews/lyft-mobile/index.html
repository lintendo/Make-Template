使用建议

建议

  • 建议：Make the map full-screen and edge-to-edge — it is the primary surface。
  • 建议：Put every control in a rounded bottom sheet that slides up with a spring。
  • 建议：Use Lyft Pink ({#FF00BF}) only for the primary CTA, active ride-type, and the pickup pin。
  • 建议：Use very rounded geometry — 28pt sheet corners, 16pt buttons, pill map controls。
  • 建议：Render the ride-type selector as a list with vehicle icon, name, sub, ETA, and a right-aligned tabular price。

避免

  • 避免：add a bottom tab bar — Lyft navigates via map + sheet, not tabs。
  • 避免：cover the map with opaque chrome — controls float or live in the sheet。
  • 避免：use pink for decoration, dividers, or body text — it's the single action color。
  • 避免：use sharp corners — the soft, rounded personality is core to the brand。
  • 避免：make the sheet appear without the spring — the bouncy entrance is the signature feel。
