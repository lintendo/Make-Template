使用建议

建议

  • 建议：Use Todoist Red {#DC4C3E} for the FAB, the brand mark, the P1 flag, and primary CTAs — verbs only。
  • 建议：Give the FAB a tinted red shadow {rgba(220,76,62,0.35) 0 6px 16px} — not generic black。
  • 建议：Use the four-tier priority system exactly as defined: P1 {#DC4C3E}, P2 {#EB8909}, P3 {#246FE0}, P4 gray outline。
  • 建议：Use SF Pro Display for display sizes and SF Pro Text for body — no custom face。
  • 建议：Keep the task list edge-to-edge with 0.5pt {#EEEEEE} dividers; the row is the layout。

避免

  • 避免：use pure black {#000000} for body text — {#202020} is the correct value。
  • 避免：use Todoist Red for ambient decoration — it's reserved for the brand mark, FAB, P1, and primary CTAs。
  • 避免：add color blocks behind task rows — task rows are always white, the color comes from the priority checkbox stroke and the project dot。
  • 避免：replace the FAB shadow with a generic black drop-shadow — the tinted red shadow is signature。
  • 避免：use a custom font — Todoist is intentionally a native iOS citizen with SF Pro。
